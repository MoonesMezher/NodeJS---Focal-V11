What Does “Server” Actually Mean?

A server is a computer/system that provides services or resources to other computers.

1. The machine
A computer running somewhere (cloud, office, your laptop in class…).
2. The software
A program listening for requests and providing a service (your Node.js app).

Server computer + Backend application = a service that receives requests and sends responses.
