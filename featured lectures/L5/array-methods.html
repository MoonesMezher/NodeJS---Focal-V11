Array Methods

Seven tools. One job each. Know which to reach for.

map filter reduce forEach every some find

Coach: Moones Mezher · Advanced JavaScript 2 — Arrays in practice.

When to use which?

Ask one question first — the answer picks the method.

1

Need a new array of transformed values? → map

2

Need a subset that passes a test? → filter

3

Need one result from many values? → reduce · one item? → find

4

Need a yes/no? → every / some · side effects only? → forEach

All seven leave the original array alone (they do not mutate it).

Transform

[].map()

Creates a new array by running a function on every element.

Returns: new array (same length) Does not mutate
const prices = [10, 20, 30]; const withTax = prices.map(p => p * 1.1); // → [11, 22, 33]

Use when… you need one output value for every input value (reshape, format, convert).

Select

[].filter()

Keeps only elements that pass a test — drops the rest.

Returns: new array (0…n items) Does not mutate
const scores = [40, 75, 90, 55]; const passed = scores.filter(s => s >= 60); // → [75, 90]

Use when… you want a shorter list of matching items, not a yes/no or a single item.

Side effects

[].forEach()

Runs a function for each element — and returns nothing useful.

Returns: undefined Use for side effects Does not mutate (callback might)
const names = ['Ada', 'Lin']; names.forEach(n => console.log(n)); // → logs each name; result is undefined

Use when… you only need to do something (log, push elsewhere, update DOM) — not build a new array. Prefer map/filter when you need a value back.

Accumulate

[].reduce()

Folds the array into a single value — number, object, string, even another array.

Returns: whatever you accumulate Does not mutate
const nums = [1, 2, 3, 4]; const sum = nums.reduce((acc, n) => acc + n, 0); // → 10

Use when… many → one (totals, grouping, building an object). Start with an initial value — it keeps edge cases clear.

Boolean checks

every() & some()

Answer a yes/no question about the whole list.

every()

True only if all pass the test.

boolean no mutate
[2,4,6].every(n => n%2===0) // true

some()

True if at least one passes.

boolean no mutate
[1,3,4].some(n => n%2===0) // true

Use when… validation (“are all emails valid?”) or existence (“is any item out of stock?”) — not to collect matching items (that’s filter).

First match

[].find()

Returns the first element that passes a test — or undefined.

Returns: element | undefined Does not mutate
const users = [ { id: 1, name: 'Ada' }, { id: 2, name: 'Lin' } ]; const user = users.find(u => u.id === 2); // → { id: 2, name: 'Lin' }

Use when… you need the item itself (not a boolean, not a list). Sibling: findIndex returns the position.

Cheat sheet

One glance — purpose, return value, mutation.

Method Purpose Returns Mutates?
map Transform each item new array (same length) No
filter Keep matching items new array (subset) No
reduce Fold to one value accumulator result No
forEach Side effects only undefined No*
every All pass? boolean No
some Any pass? boolean No
find First match item | undefined No

*forEach itself does not mutate; your callback might change objects inside the array.

Remember the shape

Build values

  • map — transform list
  • filter — subset list
  • reduce — fold to one
  • find — first item

Ask or act

  • every — all true?
  • some — any true?
  • forEach — side effects

Choose by what you need back — array, item, boolean, or nothing.
